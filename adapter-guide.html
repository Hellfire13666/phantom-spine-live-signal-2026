Know exactly what each adapter does

PHANTOM SPINE v0.2.0 uses an independent public HTTPS DNS engine, optional HEXBAZAAR v0.1.2-rc1 public-source commands and optional RIFTSEAL SHA-256. All three primary modes have dated owner-side Debian verification. A detected adapter alone is not evidence of a working provider.

INCLUDED

Native public HTTPS DNS

Direct real Google and Cloudflare HTTPS requests. Google: A, AAAA, MX, NS. Cloudflare: A and AAAA. No HEXBAZAAR dependency. Owner-run Debian test returned 6 real observations from 6 usable HTTPS DNS queries; zero accepted Cloudflare answers are documented.

OPTIONAL · LIVE VERIFIED

HEXBAZAAR v0.1.2-rc1

Only the Rosie Savage adapter at ~/PhantomLabsLaunchers/hexbazaar-savage-intel-shop-v0_1_2_rc1_rosie_savage/hexbazaar_savage_intel_shop_v0_1_2_rc1.py. Adapter used real provider responses on Debian (113 unique public observations, 4 usable providers, October 21, 2026). Current observations may vary.

OPTIONAL · VERIFIED

RIFTSEAL

The adapter release searches ~/PhantomLabsLaunchers/riftseal-evidence-forge-2026/riftseal_evidence_forge.py (plus its documented alternate). The bridge expects SHA256 and BYTES fields, independently checks both. Debian RIFTSEAL round-trip passed, returning a matching independent SHA-256 and 8,826 bytes. Native local SHA-256 also works without it.

LEGACY · SEPARATE

Original PHANTOM SPINE v0.1.0

Older adapters refer to HEXBAZAAR v0.1.0. Those pages are historical, not v0.2 live integration evidence. Keep older installations intact; prefer this guide and its version-specific short launcher for current adapter instructions.

Step 1 · Check installed adapter locations (offline)

"$HOME/.local/bin/phantom-spine-live-v020" shop

FOUND means only a regular script file was detected. It is not a successful live provider call.

Step 2 · Test genuine live public DNS

"$HOME/.local/bin/phantom-spine-live-v020" hunt example.com --engine native --providers dns --timeout 5

Look for [OK], a public provider URL and UNIQUE PUBLIC OBSERVATIONS, or a clear provider failure. Zero observations are possible.

Step 3 · Test the installed HEXBAZAAR bridge

"$HOME/.local/bin/phantom-spine-live-v020" hunt facebook.com --engine hexbazaar --providers dns,ripe,certspotter,urlscan --timeout 4 --limit 100

This launches the actual installed HEXBAZAAR v0.1.2-rc1 process, requests public providers and streams status/provenance. A network failure is not a test PASS; share provider statuses, not secrets.

Step 4 · Compare a real local file with RIFTSEAL

"$HOME/.local/bin/phantom-spine-live-v020" evidence --file "$HOME/PhantomLabsLaunchers/glitchbyte-phantom-labs-master-hub-v0_2_0/index.html" --via riftseal

If RIFTSEAL is unavailable, use the same command with --via local to get a genuine local SHA-256 without a companion tool.

Important: All the commands above run real code. Offline tests verify logic. Whether the public DNS/HEXBAZAAR providers succeed on your Debian connection is still unknown until those commands are actually run there. Never label shop alone as a live verification.
All examples are real operations, not guarantees of nonempty results. Only public-source research and local files, no private account access.
