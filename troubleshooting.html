Quick fixes for real adapter problems

Tool says HEXBAZAAR missing

The bridge uses the exact Rosie Savage v0.1.2-rc1 script path, not the legacy v0.1.0 path. Confirm you installed v0.1.2 separately; shop detects the script. It does not download companions or rewrite old folders.

FOUND, but zero observations

FOUND only means a file exists. Run the real hunt test. If 429, timeout or DNS errors appear, the provider may be unavailable or throttling; preserve partial results, reduce provider count, or retry later. Do not substitute sample findings.

New launcher opens an older version

Use phantom-spine-live-v020, not the existing phantom-spine-live RC1 alias. v0.2.0 installs a separate launcher so older icons and tool installations stay intact.

RIFTSEAL bridge unavailable

RIFTSEAL is a genuine local file-hashing tool, not an internet engine. Use native --via local first. The optional bridge requires its installed script and an expected SHA256/BYTES format.

See exact supported commands

"$HOME/.local/bin/phantom-spine-live-v020" --help

Start again with live public DNS

"$HOME/.local/bin/phantom-spine-live-v020" hunt example.com --engine native --providers dns --timeout 10

For slow connections, a 10-second per-request timeout may help. Ctrl+C stops work. Provider success is not guaranteed.

Open current guide instead of old pages

If Master Hub Installed Page Finder presents a legacy page first, select the Live Signal v0.2.0 index.html entry. Existing public Master Hub v0.2.0 itself has not been repackaged, and cannot automatically replace its historical PHANTOM SPINE recipe card without a separate Hub release.
